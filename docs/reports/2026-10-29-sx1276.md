# 2026-10-29: could the SX1276 replace the LR2021?

Question from the user: does the SX1276 support FLRC, and is its bandwidth
acceptable? **No to both; no driver written.**

- No FLRC. The SX1276/77/78/79 have LoRa and FSK/OOK modems only. FLRC is
  on the SX128x (2.4 GHz) and the LR2021 (RadioLib: `beginFLRC` exists only in
  `SX128x` and `LR2021`).
- FSK tops out at 300 kbit/s (RadioLib `setBitRateCommon` range check), uncoded
  (no inner FEC, so no coding gain), and the FSK FIFO is 64 bytes.
- Capacity with the same per-hop budget as our LR mode (100 Hz hops, beacon
  per hop, RS 8/12; estimated timing):

  | Radio / mode | Packet | Video capacity |
  |---|---|---|
  | LR2021 FLRC 520k CR 3/4 (current LR mode) | 203 B x 2/hop | ~204 kbit/s |
  | SX1276 FSK 300k, 64-byte FIFO | 60 B x 4/hop | ~102 kbit/s |
  | SX1276 FSK 300k, FIFO refilled in flight | 143 B x 2/hop | ~140 kbit/s |
  | SX1276 LoRa SF6 / 500 kHz | | ~20 kbit/s |

- Packets longer than 64 bytes need the FIFO refilled during transmission;
  at 300 kbit/s it drains in 1.7 ms, a deadline the RV1103 cannot meet
  reliably from Linux userspace over SPI.
- Sub-GHz only: no HQ (2.4 GHz) mode.

Against the CLAUDE.md fixed decisions (both modes FLRC) and the LR target
(~330 kbit/s), the SX1276 is not a fit.
